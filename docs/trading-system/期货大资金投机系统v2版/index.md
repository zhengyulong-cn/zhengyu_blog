# 期货大资金投机系统操作手册 v2

## 30F 分析

30F 图上，主要看 3 个：

- 线段类型
- 关键潜在阻力点位

|            | 操作思路                                                     | 潜在阻力点位 |
| ---------- | ------------------------------------------------------------ | ------------ |
| 趋势推动段 | 沿着趋势推动段方向操作                                       | 前高前低     |
| 趋势回调段 | 在 30F 图观察在 EMA20 附近是否受阻。受阻则操作反转，最终 30F 回调段结束。未受阻则顺回调段方向操作，回调段可能转化为趋势推动段。 | EMA20        |
| 区间内部段 | 观察在区间上下轨附近是否受阻。受阻则操作反转，未受阻就不要操作。 | 区间上下轨   |

趋势推动段的 MACD 红绿柱缩短时要小心操作，可能就很难有较大力度的走势段了。

趋势回调段的 MACD 红绿柱缩短预示着可能回调段可能结束，后续会出现不错的推动段机会。

区间内部段的 MACD 红绿柱缩短意味着改方向的内部段可能要结束。
