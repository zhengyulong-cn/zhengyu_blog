## 铁矿石 2701

30F：空头趋势，开仓时候为趋势回调段，因此择机做空

关键位：距离前低有一段较远距离。

5F：

- 第一次：5F 出现头肩顶，做空。
- 第二次：止损后第二次开空，价格上涨出现 3 次多头受阻，因此开空，符合开仓结构。

开仓信号：阴包阳，MACD 红柱缩短。

::: danger

值得注意的是开空结构的头肩顶要求低点是低于颈线的，这单交易不满足低于颈线条件。

:::

早盘铁矿石暴跌，但没有及时平仓止盈，下午铁矿石继续下跌才主动止盈。

**当第一次持仓量不断减少时，就应该止盈离场的。** 然后回撤后下午继续开空，再次操作。
