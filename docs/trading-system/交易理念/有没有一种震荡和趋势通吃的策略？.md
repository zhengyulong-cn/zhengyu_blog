# 有没有一种震荡和趋势通吃的策略？

绝不可能，不要自误。

虽然我经常自评有魄力，有勇气，敢重仓，但是从某种意义上讲去做震荡策略的交易者才是真的猛士。

我是因为恐惧不确定性，才被迫去寻找高确定性的机会，而高确定性的机会很少，从小时间级别去看，成本优势又不足，想要赚钱所以不得不重仓——本质上讲我是因为胆小而不得以去变得勇敢。

做震荡策略的交易者不同，你从任何一个时间周期去看，震荡的区间总是远远多于趋势区间。

但是，你所看到的某一级别上的无序摆动，本质上是更大周期的多空双方正在关键的价值区间进行殊死争夺，盘面的波动并非由该级别的趋势交易者推动，而是由更高级别的参与者抢筹与防守所致，任何一方在此确立优势，都将吸引海量的小级别顺势资金涌入，形成助推趋势的合力。

这正是利用大级别回调结构完整后，切换至小级别捕捉起爆点的逻辑根基。

表面上看，价格似乎在几条趋势线构成的箱体内规律运行，但这实则是两个巨人正在你眼前近身肉搏。你若进场捞取短差，本质上是在炮火连天的战壕里捡硬币，根本无法判断胜负会在下一秒还是下一小时分出。

也就是说，**震荡策略的交易者，必须分仓轻仓，有合适有机的盈亏比，胜率，频率比例，和近乎变态的纪律执行力才有可能在市场上存活下来。**

你想要什么，交易逻辑和交易系统就会相应的演化成什么。

看出来什么了不？在震荡策略的防守边界，很可能是一个趋势交易者的进攻节点，整个交易逻辑是完全相反的。

::: details 批注

震荡的边界，到底是交易延续震荡，还是做震荡突破？这是个非常纠结的问题。

:::

事实也证明如此，我有两个做震荡策略的朋友，但凡我净值高歌猛进的时候，他俩都在痛苦回撤，相反也一样，他俩收益节节攀升的时候，我要么干瞪眼，要么在磨损。

风格完全不匹配的系统绝不可能兼容——某些时候我的日内策略和趋势策略是吻合的，但是震荡真是南辕北辙。

人不能既要又要，再说一遍，不要自误！
