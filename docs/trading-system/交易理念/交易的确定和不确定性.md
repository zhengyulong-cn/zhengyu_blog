# ⭐交易的确定和不确定性

市场在本质上是一个高阶随机过程，其价格轨迹的不可预测性是唯一具有确定性的系统参数——有点绕，**价格涨跌的不确定性是唯一可以确定的事**，仔细揣摩体会下这句话。

关于行情方向变动的偶然性问题，其根源在于价格行为的时间不可逆性与信息到达的随机性。原本呈现趋势推进结构的行情，可以因为一个外生冲击事件而迅速切换至反方向运动，反之亦然。**这一特征并非市场的缺陷，而是市场的本质。**

试图以完全预测为目标来构建交易系统，本质上是在试图消除市场结构的内生随机性，这超出了任何分析框架的能力边界——这就是为什么不可能存在所谓的交易圣杯。正确的切入方式是承认随机性的存在，并将系统的设计与执行建立在随机性的基础之上。即**在不可预测的市场状态空间中，定义一个可识别的子空间，该子空间内的价格行为具有非随机的结构特征，系统只在该子空间内运作，其他所有状态空间的行情波动均被定义为系统边界外的不可操作项。**由此推导出唯一可行的盈利路径，是只参与那些具备非对称赔率结构的机会。赔率优势的来源不在于对方向预测的准确率，而在于系统对机会的筛选标准。进场位置必须在结构层面具备潜在较大行情的可能性，这个“可能性”必须是事前可定义，可量化的，而非事后归因。

能否走出预期的大行情，由市场的随机过程决定，但在进场之前，该位置是否具备产生大行情的结构条件，必须能够被系统明确界定。

**结构条件通常涉及以下几个维度：**

**①该位置是否处于一个高级别结构段的平衡区间末端**

**②该位置附近是否出现了持仓量的非线性变化**

**③该位置在更小时间框架上是否形成了主动失衡的微观确认信号**

::: details 批注

①走势的生命周期

②持仓量异变

③次级别失衡信号

:::

在趋势结构已经形成方向性偏见且宏观背景未发生根本性转变的前提下，所有与趋势方向相反的突发性大幅波动，我在系统框架中默认将其归为流动性清除行为，即针对趋势方向上的弱势持仓进行的逆向清洗。这一操作假定的逻辑依据是，**趋势的转向需要足够的时间跨度和结构发育过程来完成，一个已经形成方向性偏见的趋势结构，不会因为一次孤立的大幅逆向波动而彻底瓦解其结构基础。**因此，除非出现连续多次的结构破坏确认，否则单次逆向波动的性质被定义为结构内部的次级调整，而非趋势反转。这不构成一个分析判断，而是一个系统层面的默认假设，其有效性依赖于趋势结构本身的强度与持续时间。

::: details 批注

趋势具有惯性，趋势的转向在绝大多数情况都要经历结构改变。

:::

确定性一词在交易语境下的正确定义，是指对系统输出结果的统计分布特征的确定认知

我们无法确定下一笔交易的盈亏，但可以通过足够长的回测与实盘验证，确定系统在遍历各种市场结构状态后的期望收益区间，最大回撤区间，以及胜率与赔率的联合分布。这种确定性的建立，不需要市场本身变得可预测，只需要系统的执行在统计意义上是稳定的。**确定性机会的系统定义，不应理解为高确定性的行情机会，而应理解为高确定性的结构可识别性。**

市场行情不可预测，但市场结构是可识别的，价格在时间与空间维度上所留下的轨迹，会形成可识别的结构形态，**这些结构形态在统计意义上与后续价格运动的某些特征存在关联。**

系统的任务不是预测这些关联是否会在每一笔交易中成立，而是在这些关联具有历史胜率优势的条件下，保持一致的系统暴露，让大数定律在足够多的交易次数中发挥作用

当市场经历大幅上涨后突然急转直下，或经历深度下跌后迅速反转向上，这些现象本身并不构成对系统有效性的挑战，它们只是随机过程的正常样本表现。唯一需要关注的是，在这些价格变动过程中，系统定义的结构识别条件是否被触发，如果触发了，执行，如果没有，等待。不受任何外部信息，他人观点或突发新闻的影响，只对结构本身的演化做出响应。

等待本身不是一种消极的状态，而是系统对当前市场状态不满足操作条件的标准响应输出。在这个框架下，**寻找确定性被重新定义为，构建一个结构识别的边界条件集合，使其能够从随机价格轨迹中筛选出那些在统计意义上具有非随机特征的子集，并在这部分子集上保持一致的暴露策略——只做看的懂的行情。其余所有波动，都不属于系统需要解释或应对的对象——看不懂的行情一律不碰，更不必去探究其背后的成因。**

市场如何变动都可以，系统只需要在市场变动的轨迹上检查条件是否被满足。满足则执行，不满足则等待，这是一个由结构条件而非主观判断驱动的状态机。
