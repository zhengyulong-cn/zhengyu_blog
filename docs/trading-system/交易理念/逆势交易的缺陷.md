# ⭐逆势交易的缺陷

短线逆势交易最危险的地方，不是它不能赚钱，而是它会让你在错误的方向上赢得足够久。行情上涨时，你可以抓回调，行情下跌时，你可以抢反弹。

连续几次做对之后，你会产生一种能力错觉，我知道大方向在哪里，但我不一定非要顺着它做，即使站在反方向，我也有能力处理。第一次逆势赚了，第二次逆势又赚了，系统会把“逆势可盈利”写入你的执行数据库。之后你遇到趋势加速时，会用更大的暴露去重复这个动作。你赚到的是趋势的一次呼吸，亏掉的却是趋势本身。你赚的是局部波动，亏的是主方向，典型的捡了芝麻，丢了西瓜。

一段上涨趋势里，价格当然会回调，会震荡，会出现背离，也会不断给逆势者短暂的赚钱机会。但局部回调不等于原趋势已经结束。这种交易会形成一种特殊的收益结构，大部分时候赚一点，偶尔止损一次，然后再赚一点。

账户看起来很稳定，胜率甚至很高，直到某一次行情没有像以前那样回调，而是直接进入加速。你第一次做空被止损，你觉得位置更高了，于是再次做空，第二次又被止损，你开始相信它已经严重超涨，再做一次。前面五次，十次逆势赚到的钱，可能就在这一段加速里全部还回去。十次里面做对七次，依然可能是一套负期望系统。

问题在于，**逆势交易想维持高胜率，通常只能把止盈放得很近，把止损留得很远。因为你要赚的只是一小段回调，但你面对的却可能是整段趋势继续扩张。**反过来，如果你想用很小的止损换取高盈亏比，又会被趋势中的正常波动反复扫出去。所以，如果没有明确的关键位置，结构破坏和独立的统计优势，短线逆势很难同时拥有高胜率，好盈亏比和稳定执行。多数时候，你只能得到其中一部分，剩下的那一部分会在长期里向你收费。正确的做法永远是顺大势。

交易系统的层级结构是由决策权限的分配方式决定的。一个人可以看很多周期，也可以只用一个周期，但只要他还没有明确哪一个周期拥有“是否入场”的最终裁决权，他的系统就仍然处在信号互相覆盖的混沌状态。

主周期是唯一拥有入场决策权的层级。它负责生成结构偏见，负责定义方向性约束，负责判断当前市场状态是否满足系统开仓的条件。小周期不具备这个权限。小周期的作用只有一个，在主周期已经授权入场之后，寻找更优的入场价格。它不能反向输出方向判断，也不能在小周期信号被破坏时自动触发系统状态的切换。

小周期信号失效，只意味着这次没有拿到理想的价格，不意味着主周期的方向偏见被否定。是否离场，仍然要回到主周期去判断。离场价格的优化，同样可以交给小周期，但离场决策本身必须由主周期做出。

大周期则提供更高层级的约束，它不参与入场触发，只用于提高主周期信号的可靠度，最低要求是不要逆大势。

把这三个层级的权限分清楚，周期关系就从模糊的“共振”变成了刚性的决策分配。不扛单，不用加仓破坏成本优势，不因为一次逆势盈利就改变系统的权限分配。

系统要做的，是**把是否入场的决策权锁死在主周期，把执行价格优化交给小周期，把方向约束交给大周期，然后把所有短线逆势的诱惑排除在决策权限之外。市场会奖励逆势者足够久，久到他们误以为自己拥有超越结构的能力。**

逆势交易就是诱惑，某一两次可能会盈利，但长期看必然会因为逆势而犯错。
