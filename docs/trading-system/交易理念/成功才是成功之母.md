# 成功才是成功之母

我曾在想法区说过，对于交易者新手而言，最大的幸运莫过于在一开始就用正确的方法，走正确的路径，得到正确的结果。

很多人说失败是成功之母，至少对交易而言，这是完全的错误，**成功才是成功之母**。

市场常带来一种错觉，可通过机械性的重复训练获取线性增长。然而现实法则截然相反，净值的剧烈波动会持续冲击交易者的情绪阈值，而心理状态的失稳，必然导致有效认知经验的边际转化率被极度压制。任何一次毁灭性的资金回撤，其引发的认知重构周期往往以月甚至季度为计。

失败并不是燃料，失败只会侵蚀情感系统，它不会自动转化为能力。真正推动系统迭代的，是成功经验的可复刻化，把那些让你获利的决策路径，结构条件，执行动作识别出来，并在下一次同构场景中重复调用。

我为什么反复强调最幸运的开始是用正确的方法，得到正确的结果。

有两条常见的错误入门方式。**错误的方法，反而因为一时的幸运，得到了正确的结果。这会导致你在错误的路径上一路狂奔，直到凭运气得到的，用实力十倍百倍的还回去。或者，用正确的方法，但是因为市场当下的风格不匹配，没有得到正确的结果——这非常常见，绝大多数成熟成功的主观交易系统，都是相对低的胜率和相对高的盈亏比构成的。失败会让你犹疑，摇摆，反向的扭曲本来正确的方法论，导致走很多的弯路。**

性公而明，情偏而暗。尽管高频的微幅回撤同样会催生心理摩擦，但这种摩擦性损耗与灾难性暴击造成的心理撕裂，完全不在一个量级。所以不要大亏！**保护本金，活着，永远拥有第一优先权。**

再稍微聊聊新手常见的弯路，就是太过于苛求的寻找某种圣杯。在永远潜伏着反例的市场里，寻求证实是一条死胡同。而证伪的路径，则可以经由具体的结构条件，被进行严密且无歧义的参数化界定。真正的市场老手，习惯以假设前置，推演过渡，证伪收口来形成逻辑闭环，绝不会用无止境的证实去喂养盲目信念。

交易为什么难以像手艺一样稳定进步？因为手艺的反馈回路是线性的，交易的反馈回路是概率性的。手艺的失败只消耗时间，交易的失败会消耗情感系统与认知容量。你对系统的理解不够深刻，执行就一定会变形。

知不深，行不远，知不正，行不对。

祝刚上路的你们，用正确的方法，早点成功，快点成功。
