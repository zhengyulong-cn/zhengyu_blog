# ⭐新闻与消息

在交易中，导致决策失准的信息类问题，其根源可以被追溯至两个层面：

①信息在到达你之前的传播路径

②信息在到达你之后的认知加工路径

这两个层面是串联的。

传播路径决定了你接收到的信息集本身是什么形态，认知加工路径则在这个形态之上叠加了一层与持仓状态绑定的扭曲。

信息在到达你之前，已经经历了一轮筛选与排序。**财经媒体，快讯推送，研报摘要，社群讨论等等这些渠道不会直接编造事实，但它们会通过选择呈现哪些事实，以什么顺序呈现，搭配什么样的解读框架，来引导你的认知方向。**定向投喂的核心在于信息的可见性分配，你看到的，是被允许看到的，你没看到的，可能恰恰是结构判断所需要的关键变量。

在交易市场，这种定向投喂的典型载体是小作文和快讯。一篇没有成本的小作文可能在几分钟内驱动一个品种的短期波动，而写它的人不需要为你的亏损承担任何责任。这就是为什么在**判断一个信息源的可靠性时，最核心的标准不是它说得对不对，而是它有没有为自己的判断付出成本。**

不用付出成本或者极为廉价的建议，都应弃之如敝履。用脚投票，知行合一的前提是行在知先。但获取环节的问题，尚不是最难的。真正难以翻越的，是信息在到达你之后所经历的认知筛选。**满仓的时候，你看到的所有信息都倾向于被解读为利好。空仓的时候，同样的信息集会被倾向于解读为利空。**信息本身没有变，变的是你的持仓状态的倾向性偏好解读。仓位决定立场，立场决定你看到的世界。这就是我执，就是确认偏误的底层机制。

::: details 批注

大部分时候，同一个标的会同时出现利多和利空，而持仓或空仓产生的偏好会导致对偏好信息的放大，对不偏好信息的忽略。

:::

以物观物，性也，以我观物，情也，性公而明，情偏而暗。不带任何主观立场进入观察，事物呈现其本来的结构。**带着我的利益进入观察，事物就被情绪与偏好所遮蔽。只要带了立场，就必然带有性情，带了性情，认知就失去了公正性。**

有一个被反复验证的规律值得注意，**那些足以重塑定价逻辑的基本面催化剂，无论利多还是利空，通常都要等到大级别上涨或下跌结构完成蓄势之后，才会被推上台前。甚至其实走势最终夭折，关键技术点位上也会有消息被抛出来，测试市场还剩多少决心。**这便意味着，倚重基本面信息来下单的人，几乎注定会错过技术面最理想的入场时机。

::: details 批注

每次大行情的基本面驱动逻辑，往往是事后才能看到的，此时肯定是错过技术面的最佳入场点的，基本面只是入场的背景依据。

:::

基本面消息可以用来判断哪些板块有资金流入和流动性聚集的潜力，这些是形成大热板块的基础条件。但不要依赖任何基本面消息做开平仓决策，它是一个背景，也只能是个背景。

破除信息投喂的第一种能力，是反事实模拟。你要意识到事物不止一面，很多关键信息可能被刻意隐藏了。从草蛇灰线的蛛丝马迹中拼凑出另一个版本的解释。你拼凑出的那个版本，不需要是准确的，只需要与主流叙事保持不相关。你不需要证明市场是错的，你只需要不被市场的信息投喂所俘获。不相关本身就是一种结构性优势。

**当你的入场决策依据的是结构条件是否被满足，而不是你希望它朝哪个方向走。当你的离场决策依据的是结构前提是否被否定，而不是你在这个位置投入了多少情感。我执在这个系统中的权重就被压缩到了最低。**

你需要区分哪些信息是有结构背景的，哪些信息只是定向投喂的噪声。当你掌握了在起爆点精准开仓的技能之后，你会反复观察到同一个规律，形态先就绪，消息后到达。这个观察本身就是对基本面交易逻辑的结构性证伪。
