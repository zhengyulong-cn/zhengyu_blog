# 过滤震荡噪音

市场 80%的时间在震荡，对于趋势交易者来说这就是标准的垃圾时间。不客气的说，市场上 90%的所谓“震荡策略”都在慢性自杀。震荡是多空分歧没决出胜负，双方还在集结兵力。这时候冲进去尝试在一定区间里低买高卖，安全边界非常脆弱。虽然没有压路机前捡钢镚那么夸张，但是也离得不远了，我本身是非常排斥这种交易逻辑的。

非要做也不是不行。**至少震荡区间必须足够宽。宽到什么程度？宽到区间内部的波动空间，能容纳一个小周期结构的完整展开——从收敛到扩张，从订单块到主动失衡，流程一个不能少**。区间窄得像条缝，小周期趋势刚启动就撞上大周期结构位，纯粹找死。如果周期调小了也做不了，就不做。不做什么都别做，空仓是交易的一部分，而且是盈利最大的一部分。

::: details 批注

宽幅震荡区间是可以操作的，因为次级别能容纳结构的完整展开。窄幅震荡区间就不要做了，就是垃圾时间。
:::

其次小周期趋势的运行空间，不能挑战大周期的压力边界。顺势的本质是空间，不是方向。**震荡区间的上沿和下沿，是大资金布防的关键结构位**。小周期哪怕走出完美的主动失衡，只要等距投射撞进上沿 3%以内，这笔单的盈亏比就已经被破坏。那些上沿的挂单，是机构在等待流动性送上门来清扫，你进去就是猎物。

震荡区间低买高卖为啥在我看来很鸡肋——要不是确实认识两个纪律达人真能用这个模式挣钱，我真想说是垃圾。

一段规整的区间，上下沿不是多方和空方商量好画出来的。价格跌到下沿反弹，不是多头在吃单，是空头把挂单撤了，卖压暂时消失，价格因为缺少卖盘自己浮上去。这种反弹没有持仓量支撑，没有主动失衡进场，给你看到的反弹只是流动性真空。你在流动性真空里开多，等于在雪崩后的松雪层上搭帐篷。

上沿出现主动卖出，持仓量增加、价格被打回；下沿出现主动买入，持仓量增加、价格被托起。两边都出了真金白银的主动失衡，但都被对方的结构位硬吃了回去，只有这时候进入了一个短暂的多空战略平衡期——双方都在重新集结，谁也不想在这个时候主动出击。盘面上表现成：波动率急剧收窄，成交量萎缩，持仓量走平或微降，才是在我看来比较安全的震荡策略区间。

趋势最多的时间就是等待，等的结构是什么？**低位收敛之后的主动失衡**。你现在把震荡区间理解成一个更大级别的收敛结构就对了——区间内部的多空平衡期，就是这个大级别收敛的“订单块”。持仓量在区间内沉淀，多空都在建仓，分歧在积累。突破的那一天，双量共振，一方把另一方吃掉，趋势启动。

::: details 批注

收敛后的主动失衡，就是调整结束的时机。
:::

**不要研究震荡怎么做，要研究震荡什么时候死。** 震荡的死亡方式确定性是比较高的，**当波动率降到冰点，持仓量积累到极端，然后某一刻，主动失衡在某一侧边界爆发，成交量持仓量同步放大，趋势出生**。这才是你扣扳机的唯一时刻
