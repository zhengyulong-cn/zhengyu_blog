# ⭐看对方向还亏钱

趋势的方向判断并不构成盈利的充分条件。“有趋势”和“有值得参与的趋势”还差的非常非常远。所以必须引入过滤条件，我会在我能分享的边界极限内阐述的足够详尽。

首先就是位置，关键位应当被处理为有厚度的区间，而不是一条精确线，支阻互换区、密集成交区、大级别结构位等，才具备被纳入观察池的资格。

其次是力度，一笔暴露能否转化为收益的，这段推进所携带的结构能量非常重要。**能量不足的趋势，会在你建立头寸之后反复消耗你的风险预算与心理容量；能量充沛的趋势，则会在你介入之后持续承接浮盈，让价格以更高的推进效率脱离成本区。** 判断结构能量的工具，不是任何技术指标，指标是对已发生价格轨迹的平滑映射，它描述过去，不构成对未来推进强度的有效约束。判断力度最可靠，也几乎是唯一的维度，是时间。**同一段空间位移，消耗的时间越短，结构效率越高；反复冲高又收回，围绕同一价格区域来回折返，即使最终创出新高，推进效率也已经下降。谁用更短的时间推动了更远的距离，谁就占据了结构的主动权。** 这就是我为什么在不同文章中反复强调量能。

最后是逆向回撤的衰减幅度以及筹码交换的充分性。**前段行情的推进段过度剧烈会极大地消耗了某个方向的势能，市场必须通过足够深度的修正来完成筹码的良性换手，从而为后续的趋势延展腾出空间**，所以这是回调的必要性。回调的力度和深度则在很大程度上影响小周期上是否值得介入——这跟赔率直接相关。**筹码充分交换本质上是共识重构的过程，这个过程是向上一致性预期的凝聚，卷入博弈的异质化资金主体越庞杂，期间博弈越剧烈，可能产生的行情就越有穿透力。** 没有大级别的能量蓄积，几无可能有大级别趋势的横空出世。

::: details 批注

根据大级别找操作方向是很明确的，但这并不意味着就能赚钱。在实盘操作过程中，空头趋势做空就一定赚钱吗？未必，因为哪怕是空头趋势中间也会有回调，如果在趋势末期做空，一个回调就会导致连续亏损。另外在回调位置做空，如果回调未结束，也会多次止损。那么在看到明确趋势情况下进行过滤，用到三个条件：

1.关键位。价格到达已有关键位或高低点构成的潜在关键位都有可能受阻而反向。

2.走势力度。那些不错盈利的单子，往往是开仓后就很快脱离成本价，走势力度强，推进效率高。走势力度的判断就是看推进空间位移消耗的时间，类似于平均速度。

3.筹码充分交换。说实在话，这点我还没有领悟到。

:::

这是通用的逻辑大框架，可以嵌合到任意种交易系统内，但并不意味着没有其他有效的过滤条件。比如鉴于移动平均线承载了相当体量的群体交易共识，以均线系统作为前置的过滤矩阵，就能有效规避那些动能匮乏的低质量区间。这部分丰俭由人，我个人是如无必要勿增实体。

需要强调的是，上述所有条件没有一项符合，行情能走出来的可能性依旧存在。这种高度不确定性本身就是市场的魅力所在——当然也是风险所在。

怎么处理？不处理，无视即可。月盈则亏，不必苛求完满，承认自己的能力边界，赚自己能力边界的钱。
