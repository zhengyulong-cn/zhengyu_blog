# 期货逼仓

逼仓行情在结构层面的根本驱动力，来自交割机制中多空双方义务的天然非对称。多头只需要交付资金，空头却必须交付符合标准的现货，生产，运输，入库，注册，每一步都消耗时间与成本。**资金的获取远比现货的获取容易**，这是交易所早已公开的结论，钱比货多，所以多逼空的发生频率远高于空逼多。一百年的期货史里，十次逼仓有九次是逼空。反过来，空逼多几十年才出现一次，最极端的案例是原油包黑天鹅，但那次需要多头在物理层面接单运输费用成本高企才能实现。这种非对称在价格空间维度上被进一步放大。

价格向下有刚性底线，跌到零就没有燃料了，向上没有顶，顶在哪里取决于下游真正用不起的位置。多逼空可以在极短时间内完成巨大的空间位移，而空逼多的空间始终受限于这个刚性底线。在时间轴的演化路径上，逼空与空逼多两种极端行情呈现出截然相反的速率特征。

在极端单边行情末端里：

- **逼空格局的尾段往往进入抛物线性加速，空头在追加保证金通知的压力下被迫回补，回补行为本身推升价格，进而触发更大范围的空头强制平仓，形成一个自我强化的踩踏级联。**
- **空逼多格局的尾段则表现为动能衰减，多头遭强制平仓后，其损失上限即为本金归零，能量释放完毕便戛然而止，无法催生同等量级的连锁反应。**

这也解释了为何当交易所上调保证金要求时，最先被清算出局的通常是空头一方，在上涨结构中，追加保证金压力优先碾压的是逆势持仓者。两种极端格局的终结机制，同样呈现出结构性非对称。空逼多的收束路径相对明确，多头承接实物后离场，行情便随之收敛。

然而多逼空无法沿同一逻辑落幕，空头即便甘愿认赔，也缺乏将资金头寸转化为实物交割的通道，现货的稀缺性构成硬约束，空头唯有被动接受高位回补。抛售实物以压制价格轻而易举，反向将资金兑现为可交割现货却近乎不可能。这正是结构性逼空难以经由市场内生机制自行出清的根本症结。

回到话题初想说的最近原油化工品。

以原油为典型代表的一类，其驱动来自物理层面的供给中断，海峡通行量已萎缩至个位数，绕行管道同步关闭，此类逻辑的硬度最高，但一旦通航恢复，其崩塌也最为迅疾。

以燃油、沥青为代表的另一类，自身缺乏独立叙事，完全依附于原油的成本传导链条，一旦原油涨势停滞，其回落速度将远超原油本身

以甲醇，乙二醇为代表的第三类，现货只在近月出现可能的实质性短缺，问题更大出在可用于交割的仓单被人为锁定，此类结构最为脆弱，一旦新仓单注册入场，价格便立刻松动。

以纯碱，玻璃为代表的第四类，其驱动源自减产预期与政策文件，在原油暴涨之际反而下挫五个百分点，厂库库存高位累积，全行业陷入亏损，其短缺并非实物层面的短缺，而是情绪层面的短缺，而情绪所支撑的溢价，生命周期极短，难以维系三个交易日。

散户若拟介入此类行情，须恪守三项观察维度与三条禁止边界：

- 观察层面，**近远月价差的波动结构是否出现异动；交割月临近时持仓量是否仍在边际递增；以及现货端的波动状态是否与盘面形成共振。**
- 禁止层面，**不得在最陡峭的月差曲线上建立近月空头敞口；个人账户无法进入交割月，务必提前了结；不得在连续拉升后暴露反向头寸，切勿将涨幅过大本身作为做空的依据。**

只做主力合约，个人账户无法交割。

出现逼仓式暴涨暴跌，绝对不能建立反向头寸！

逼仓行情的末段往往最为极端，当前近月对远月的升水已处于高位，表明市场已充分定价这轮行情的紧迫程度。这是现货稀缺与空头恐慌共同制造的极端失衡。逼仓推升是空头的恐惧，而恐惧的上限，无人能够预判。

最后说点题外话。农产品板块对情绪扰动的敏感度相对偏低，其趋势架构因而呈现出更高的结构连续性与稳定性。而境内其余商品类别则更易受情绪脉冲牵引，且这种牵引并非源自外盘情绪的持续外溢，而更接近于一种资金主导下的控盘特征。
