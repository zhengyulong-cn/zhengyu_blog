# 日内交易

有人把日内短线等同于全天候开平仓，这是把交易频率误认为交易能力。日内时间框架只是执行层级的选择，它本身不构成开仓理由。内盘的每日交易窗口相对有限，价格发现过程因此显得迟滞，信号生成的密度也随之偏低。**市场在多数时间里处于对称状态，多空力量在某个价格区间内达成暂时均衡**。

信息密度低的时间窗口，价格在噪声中随机游走，强行介入只会消耗风险预算。机会的稀缺并非主观选择，而是客观约束。只有结构在时间或空间维度上形成不对称，才存在值得下注的窗口。当然信息密度高的时间窗口也有，比如重大事件密集释放，财经日历压缩未来的时段，价格运动的潜在空间与速度被显著放大，日内机会会多到一天必须全神贯注盯盘——就是此种情形较少。

所以 **采取趋势跟踪范式的参与者，通常会对多个标的构成监控池，依据机会在标的间的分布，动态选择切入方向**。标的筛选须与策略范式相匹配。以日内动量捕捉为取向的参与者，通常偏好波动区间宽广，且低时间框架下结构层次分明的合约。沿此逻辑进行筛选并不复杂，核心在于寻找日线维度上多空主导权频繁易手的标的。

最大原则依旧是看大做小。你不能因为切到了 1m 或 5m，就赋予小周期决定方向的权力。大级别结构的能量和共识会在发起位附近形成约束，使低级别暴露的亏损概率显著低于平均水平。如果偏保守，系统可以只做刚完成反转的优质趋势的第三推进段，只做二买和三买，一买不做。日内交易频率的高低是系统条件满足频率的映射。机会多时，可以密集执行，机会少时，保持空仓或极轻的观察仓位，不因为无聊手痒或错失恐惧而下注。

**如果你在小级别连续多次亏损离场，需要怀疑的是小级别入场方法本身的质量，而不是以小搏大的框架是否存在问题。** 低时间维度的结构呈现出高度自洽的秩序性，1m 级别的信号因而具备相当程度的可信度。但这一可信度的成立，必须以内嵌于高时间框架结构偏见持续有效为前提。在多空力量交汇的关键位阶，即便是 1m 乃至更细微的时间切片，亦会对该位置展现出充分的尊重。

::: details 批注

符合大级别方向时候入场频繁止损，其实就是本级别开仓时候的结构不干净。

:::

不要对日内短线抱有误解。不管是一天不开仓，还是一天开了很多次仓，目的只有一个，做自己有把握的行情，赚自己有把握的钱。趋势构成最高维度的约束框架，关键位阶构成博弈发生的物理位置。而触发信号则居于二者之间，充当执行层的扣扳机机制

洞悉结构层级者，不会与主导方向对抗；精于位阶识别者，不会进行无依据的随机介入；懂得等待触发条件者，不会被冲动驱动。交易频率只是系统运行后自然涌现的统计特征
